✦ Our Mission

AI that respects your privacy by architecture, not by policy.

Every component runs locally — from the UI to the inference engine. No data leaves your phone. No servers involved. Just you and a 500M-parameter model.

(01) The App — Chat Interface+

Built with Jetpack Compose and Material 3. Real-time token streaming, markdown rendering, dark/light theme, voice input, and conversation history management. All UI runs on the UI thread with StateFlow-driven reactive state.

(02) The Engine — llama.cpp+

C++ inference engine wrapped via the llama.cpp Android SDK (v0.0.4). Handles model loading, token generation, and system prompt management. Exposes a Flow<String> API for real-time token-by-token streaming to the ViewModel.

(03) The Model — Qwen 2.5 0.5B+

494M-parameter instruction-tuned transformer from Alibaba Cloud. Quantized to Q4_K_M (469 MB). Supports 32K context window. Ships inside the APK — no download required. Strongest 0.5B model on MT-Bench (4.82).

Capabilities Offered+

General chat, coding help, writing assistance, brainstorming, summarization, translation (English/Chinese). System prompt presets let you switch between Default, Creative, Professional, Concise, or Custom personalities.

✦ Frequently Asked Questions

Common Questions

Why a 0.5B model? Why not 7B or 13B?+

Larger models (7B+) require 4–8GB RAM just for weights and run at 2–5 tok/s on phones — too slow for real-time chat. The 0.5B fits in ~500MB, runs 10–15 tok/s, and delivers surprisingly capable responses for its size. It's the smallest viable model for fluid conversation on mobile hardware.

Is it really 100% offline? No internet needed?+

Yes. The app does not declare the INTERNET permission. It cannot make network calls. The model ships inside the APK. Everything — from the UI to the inference engine — runs locally on your device. No server, no cloud, no data transmission.

Can I use my own model instead of Qwen?+

Not yet — but multi-model support is planned for v1.2. You'll be able to swap between Qwen, Llama, Phi, and other GGUF models at runtime. For now, Qwen 2.5 0.5B is the bundled default optimized for this app.

Why no GPU acceleration?+

llama.cpp CPU inference works on every Android device. GPU (Vulkan/OpenCL) support varies wildly across OEM drivers — what works on a Pixel may crash on a Xiaomi. CPU is universal, stable, and fast enough for a 0.5B model at 10–15 tok/s.

How is my data stored? Can other apps read it?+

Conversations are saved as JSON files in app-internal storage (filesDir/conversations/). This directory is sandboxed per Android security model — no other app can access it without root permissions. No data is ever uploaded anywhere.
